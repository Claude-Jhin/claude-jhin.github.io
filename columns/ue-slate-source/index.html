UE5 Slate 原理与源码拆解

已完结

围绕 UE5.7 Slate / SlateCore / SlateRHIRenderer 内核，从模块边界、一帧主循环、SWidget 生命周期、布局、输入、绘制、失效、文本、样式、窗口到调试排障，形成一条偏原理和源码的纯 Slate 学习主线。

当前阶段：2025.01 - 2025.04 旗舰连载 已发布 16 / 16

这一栏想解决什么

  • 建立 Slate 作为引擎 UI 内核的完整心智模型，和 UMG 的 UObject 桥接层明确分开
  • 读通 FSlateApplication、SWidget、FReply、FSlateDrawElement、Invalidation、SlateRHIRenderer 等核心链路
  • 沉淀可复用的 Slate 性能诊断、焦点排障、绘制异常与自定义控件实现方法
